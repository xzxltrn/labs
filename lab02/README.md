## Инварианты DataSample

- "id" не равен "null" и не пустой (не состоит только из пробелов).
- "label" не равен "null" и не пустой.
- "status" не равен "null"; новое наблюдение создается со статусом "NEW".
- "features" не равен "null", содержит хотя бы один элемент, все значения конечные (не "NaN" и не бесконечность).
- Массив признаков копируется в конструкторе и при возврате из "getFeatures()", поэтому внешний код не может изменить состояние объекта.
- Статус меняется только через "changeStatus"; setter-ов нет.
- "normalizedFeatures()" возвращает новый массив, приведенный к диапазону [0, 1]; исходные признаки не изменяются.

## Инварианты BankAccount

- Баланс никогда не бывает отрицательным.
- Пополнение и списание принимают только положительную сумму; списание не может превышать баланс.
