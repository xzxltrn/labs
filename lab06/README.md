## Выбор коллекций

- `LinkedHashMap` хранит количество наблюдений для каждого статуса и сохраняет порядок первого появления статусов.
- `LinkedHashSet` убирает повторяющиеся источники и сохраняет порядок их первого появления.
- `ArrayList` позволяет скопировать исходный список и отсортировать копию через `Comparator` по числу признаков, затем по идентификатору.

## Дополнительная часть. Сравнение Stack и ArrayDeque

Наш `Stack<T>` хранит элементы в `ArrayList<T>` и использует конец
списка как вершину стека. `ArrayDeque<T>` тоже можно использовать как
стек с методами `push`, `pop` и `peek`. В обоих случаях последним
добавленный элемент извлекается первым, а `null` запрещён.

На пустом стеке `pop()` в обоих случаях выбрасывает
`NoSuchElementException`. Наш `peek()` тоже выбрасывает это исключение,
а `ArrayDeque.peek()` возвращает `null`.

В обеих реализациях `push()` работает за O(1) в среднем по серии
добавлений, а `pop()` и `peek()` — за O(1).
